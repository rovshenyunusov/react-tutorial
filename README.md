# 📘 React Öyrənək

**Müəllif:** Rovshan Yunusov

React-ı sıfırdan dərinliyə qədər izah edən, Azərbaycan dilində yazılmış kitab.
Hər mövzuya dörd sualla yanaşılır: **bu nədir, niyə lazımdır, pərdə arxasında necə işləyir və harada səhv salınır.**

## 📥 Yüklə

## Kitabda nələr var

- 🔹 Brauzer və JavaScript-in təməlləri: DOM, event loop, closure, immutability
- 🔹 React-ın daxili mexanizmi: render, reconciliation, Fiber, hook-ların işləmə prinsipi
- 🔹 State, effektlər, custom hook-lar, formalar
- 🔹 Server məlumatı: TanStack Query, race condition, keşləmə
- 🔹 Routing, performans, React Compiler, Server Components
- 🔹 TypeScript, Context API, Zustand, Redux Toolkit, Zod, React Hook Form
- 🔹 Arxitektura: SOLID, Feature-Sliced Design, təmiz arxitektura, design pattern-lər

Hər fəsildə sadə dildə izah, elmi tərif, tipik səhvlər, yoxlama sualları və tapşırıqlar var.

## Kimlər üçündür

- React-ı sıfırdan öyrənmək istəyənlər
- React-da kod yazan, amma "niyə belə işləyir" sualına cavab axtaranlar
- Müsahibəyə hazırlaşan frontend developerlər
